# Association Map

Association / 聯想 means PBS can connect a material, a person, a place, a workshop, a method, a tool, a zine, and a question without forcing them into one hierarchy.

The important boundary is now explicit: Semantic Layers are bridge indexes; `Wiki/*` is the compiled middle layer.

## Migration Note

Some existing folders, exports, and older notes use `daydream` as legacy/internal terminology. Do not rename those paths yet. Public-facing navigation should prefer association / 聯想 unless referring to an existing legacy name.

## How Association Works

- Raw sources provide memory material.
- Semantic layers group source pages by Tools, Concepts, Events, and source themes as retrieval hints.
- Entity layers group source pages by People, Places, and Time as retrieval hints.
- Compiled Wiki notes turn repeated patterns into source-bounded shared memory.
- Wikilinks make the compiled middle layer navigable.
