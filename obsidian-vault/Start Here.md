# Start Here

PBS should be read as a layered LLM Wiki, not as a flat source dump.

## Read In This Order

1. [[Home]] gives the current vault map.
2. [[Wiki/index|LLM Wiki Index]] opens the compiled middle layer.
3. [[Association Map]] explains how bridge indexes and compiled notes interact.
4. [[PBS Wiki Visual Map.canvas]] shows the system in Obsidian Canvas.
5. [[Questions]], [[Zines]], and [[Characters and NPCs|Characters / NPCs]] show runtime-facing outputs.

## If You Want Evidence

- Use compiled notes first and inspect their `sourceRefs`.
- Use [[Sources/PBS Semantic Layers/README|Semantic Layers]] and [[Sources/PBS Entity Layers/README|Entity Layers]] as bridge indexes only.
- Open raw source indexes only when you need to verify or strengthen evidence: [[Sources/Hackteria Full Index]], [[Sources/How To Get What You Want Full Index]], [[Sources/SGMK Full Index]].

## Four Layers

- Raw Sources: immutable evidence pages and source indexes.
- Bridge Indexes: semantic/entity/sourceCards hints for retrieval and candidate relations.
- Compiled Wiki Middle Layer: source-bounded shared memory in `Wiki/Concepts`, `Methods`, `Materials`, `Theories`, `SocialForms`, `Projects`, `Comparisons`, and `Syntheses`.
- Runtime Outputs: zines, NPC dialogue, Question Pet, and visual maps.
