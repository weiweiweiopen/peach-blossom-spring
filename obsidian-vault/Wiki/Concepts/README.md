# Concepts

Concept Pages are semantic terrain nodes. They require sourceRefs and evidence before being treated as factual.

Use this folder for durable compiled concept notes, not raw source catalogs. A concept note should link to related methods, materials, theories, social forms, projects, comparisons, and syntheses when source evidence supports the relationship.

## Required Note Shape

Every compiled note in this folder should include `type`, `id`, `title`, `status`, `summary`, `sourceRefs`, `evidence`, `relatedConcepts`, `relatedMethods`, `relatedMaterials`, `relatedSocialForms`, `relatedProjects`, `openQuestions`, and body links to other Wiki notes.
