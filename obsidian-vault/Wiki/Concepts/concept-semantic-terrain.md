# Concept Page as Semantic Terrain

A Concept Page is not an NPC profile or a zine. It is a terrain node that links local sources, NPCs, questions/pets, zines, feedback, and scene zones with explicit evidence.

## Evidence

- `specs/003-modern-PBS-scene/question-concept-page-design-report.md` defines Concept Pages as source-bounded terrain nodes. [1]
- `obsidian-vault/Schema/frontmatter-schema.md` defines the source-bounded frontmatter contract. [2]
