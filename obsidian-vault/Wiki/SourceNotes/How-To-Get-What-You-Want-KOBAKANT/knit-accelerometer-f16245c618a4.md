- When you knit with conductive yarn, it changes the resistance when stretched. So, I thought of making an accelerometer with same principle. The weight at the end pulls and stretches the knitted structure as it gets accelerated. It works the best when this sensor (more of an object) is turned around like hammer throwing, or thrown. [1]
- Here, I am using marbles as weights and bead to isolate the conductive thread connection from the bottom. [1]
- Simple testing device. Connected with Lilypad and Xbee, powered with Lipo battery. [1]
- Reading the sensor data from processing sketch. This is a modification of a “graph” sketch. It is showing the input difference. [1]
