## Evidence

- Xbee can be connected directly like an invisible wire. You can set the matching pins as one of them as input (AI/DI) and the other as output (PO/DO). [1]
- Xbee can be connected directly like an invisible wire. You can set the matching pins as one of them as input (AI/DI) and the other as output (PO/DO). [1]
- You can see this application in Wireless Tilt Sensing Bracelet, [1]
- To do this, you need to change some AT command. To access AT command, connect Xbee with computer with dongle, if you are using PC, you can use X-CTU to program it. If you are using Mac, you can use XBee Terminal Max by Rob Faludi, or make your own serial terminal communicator with your favorite program. Here is a small max patch we use made by Ingo Randolf. You can use it with max/msp runtime (free) if you do not have max license. [1]
- The example is based on the I/O Line Passing example on the Xbee series 1 manual p14. [1]
