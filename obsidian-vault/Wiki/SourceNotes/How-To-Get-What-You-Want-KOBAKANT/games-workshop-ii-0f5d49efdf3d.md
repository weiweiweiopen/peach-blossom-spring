- Time: 31th May,1st, 2nd June, 2010, 10-17h [1]
- This workshop introduces interaction and physical interface design topics through hans-on projects. Students are asked to plan a game, inspired by words describing physical actions, and develop original physical interfaces for the planned games. [1]
- Four groups were formed during the workshop to work together. Each group picked 3 action keywords and started the game concept using these key words. Conductive fabrics, threads and some hand crafting techniques were introduced to support the realization of the planned interface. Participants are challenged to create a game strategy and interface, as well as to learn basic electronics, programming and handcrafting skills. [1]
