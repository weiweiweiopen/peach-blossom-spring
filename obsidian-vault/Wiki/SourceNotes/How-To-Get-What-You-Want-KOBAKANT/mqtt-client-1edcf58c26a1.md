- This post is a follow up to mqtt broker post. [1]
- The devices that are connecting to MQTT broker (ESP, computer.. etc) is called “Client”, and on client side you will be running some kind of software that act as a MQTT client that publish/subscribe data to broker. [1]
- For example, on ESPs, we used “espMQTTclient” library (on Arduino IDE, go to Sketch/Include Library/Library Manager and type in “espMQTT” on search bar on Library Manager window), based on the provided example SimpleMQTTClient to program ESP32-Dev kit board we used. [1]
- On computers, we used Pure Data software to sonify data published from ESPs, and for this we used MQTT client external from njazz. [1]
