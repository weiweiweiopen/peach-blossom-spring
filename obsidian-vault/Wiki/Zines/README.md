# Zines

Public zine artifacts and reviewed feedback links. Public entries must avoid backend/process/source graph language.

## Feedback Routing

Heart/comment feedback belongs here only as aggregate reception metadata after review. Do not write raw comments into source pages.

Recommended routing:

- zine-level reception and recurring comments -> `Wiki/Zines/README.md` or a future reviewed zine note.
- repeated questions emerging from comments -> `Wiki/Questions/README.md` or reviewed Question Page candidates.
- review actions and promotions -> `Wiki/log.md`.
- high-volume raw feedback -> future `Review/zine-feedback/` records, not source evidence.
