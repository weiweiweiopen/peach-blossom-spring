# Questions

Question Pages are durable semantic objects. Runtime pets/thronglets are embodied interfaces for these local-first questions.

## Question Terrain State

Question Pet lint should not be a generic score. Use a small terrain state when reviewing exported/local summaries:

- `has_evidence`: the question has at least one verified local sourceRef.
- `has_relation`: the question connects two or more source pages, concepts, methods, materials, NPCs, zines, or scene zones.
- `has_contradiction`: the question carries a limit, counter-example, ambiguity, or unresolved tension.
- `missing_durable_node`: the question points to a motif or relation that should become a compiled note only after review.
- `pet_broadcast`: a short game-facing hint that can say where thought has not grown yet.

Public GitHub Pages may broadcast curated hints during play, but it must not automatically write private pet dialogue memory into this folder.
