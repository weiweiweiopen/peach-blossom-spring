## Current Runtime Data Flow

```text
Cloud mode:
  scripts/pbs_engine.py export-d1-sql
  -> Cloudflare D1 SQLite / FTS
  -> Cloudflare PBS memory Worker
  -> game UI

Local full-memory mode:
  game UI
  -> scripts/pbs_game_server.py
  -> scripts/pbs_engine.py index/search/draft
  -> SQLite / Sources / Wiki / Schema
  -> DeepSeek
  -> answer / Review draft
```

The game does not use the old browser-only JSON snapshot as runtime memory. Public cloud mode calls `pbs-memory-worker`; local mode calls the local Python server. A separate `pbs-engine-worker` directory is not the current deployed runtime for this version.
